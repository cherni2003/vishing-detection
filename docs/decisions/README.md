# Décisions techniques (ADR)

Une note courte par décision qui touche plusieurs membres de l'équipe : changement du schéma du manifest, choix de l'encodeur audio, durée des fenêtres, méthode d'agrégation, serveur MLflow, etc.

Format : `NNNN-titre.md` avec *Contexte*, *Décision*, *Conséquences*. Les changements d'interface passent par une pull request relue par les deux autres rôles.

Décisions ouvertes : serveur MLflow partagé, encodeur audio retenu, durée de fenêtre, agrégation au niveau appel, protocole de test cross-corpus.
